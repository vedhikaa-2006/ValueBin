ValueBin
ValueBin is an AI-powered smart food-waste monitoring system designed to help households understand and reduce the food they throw away.
The system uses IoT sensors and AI-based food identification to detect waste, measure its weight, identify the food category, and estimate the *₹ value of wasted food*. A dashboard provides daily waste statistics, weekly trends, detected food items, a waste-reduction score, and AI-generated suggestions to encourage better food-waste habits.

### Key Features

* 📦 Automatic food-waste drop detection
* ⚖️ Real-time waste weight measurement
* 📷 AI-based food identification
* 💰 Estimated monetary value of wasted food
* 📊 Weekly waste trend tracking
* 🏆 Household waste-reduction score
* 🤖 AI-generated waste-reduction suggestions
* 📋 Recent waste activity tracking
* 🌱 Estimated environmental impact

### Tech Stack

*Hardware:* ESP32, Load Cell + HX711, IR Proximity Sensor, Camera Module, OLED Display
*Software:* Python / AI Model / Dashboard
*Connectivity:* Wi-Fi via ESP32
